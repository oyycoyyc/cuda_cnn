# 课程 CUDA 接口实现证据

目标：GPU 推理、准确率至少96%，完整进程时间低于100ms。阶段性功能通过不表示性能目标已达到。

## Task1：主机接口与模型交接

`task-1/` 保存独立审查、修复复审、Linux测试及校验记录。新增接口在 Linux 执行48项全部通过；新48项测试链接修复前实现时能复现3项失败。无关工作目录内容保持不变，已有不明模型文件不会被覆盖。

Task1证据不涵盖GPU前向、课程官方 train/infer、完整训练或性能验收；此处不声称课程提交或100ms目标完成。完整进度见 `.superpowers/sdd/2026-10-27-course-gpu-interface/progress.md`。

## Task2：独立 GPU 前向与辅助核

`task-2/` 保存 H20 实测与独立复审证据。全新 CMake 构建全部可选目标成功，48项主机和8项GPU测试通过；同输入／权重的 logits 在批量1/17/1024与原LeNet逐位一致。固定单显存池、尾批／重复执行、无Forward分配和更小显存占用均有测试。修复了检查点静态库依赖与共享错误标志的并发写入，并在生成PTX确认原子交换。默认架构90及调用者覆盖86分别验证；不含测试／工具／训练后端源文件的最小默认构建通过。

官方 train/infer 工作流、课程训练模型及完整进程时间仍待后续任务，不把GPU组件测试通过视为100ms目标达标。

## Task3：课程训练适配

`task-3/` 保存训练接口、双epoch补充回归与独立复审记录。48项主机、8项GPU及9项训练测试全部通过，原算子回归通过；仅使用传入训练图像／标签，FP32分数像素能影响训练权重，验证集来自训练集内确定性划分。双epoch用例验证跨轮执行及严格最佳模型选择，保存后的模式／权重／CRC重新校验。默认20epoch完整训练和全量测试仍未执行，不把小样本回归当作准确率或时间目标验收。

## Task4：正式入口与推理运行时

`task-4/` 保存正式入口、运行时／计时和独立审查证据。四套测试48/8/9/15项全部通过；先用强区分夹具复现并修复批次偏移单位错误，再用真实缓冲输出故障复现并修复错误成功返回。默认最小源码构建生成train/infer，并完成有界训练→推理闭环；infer实际链接／符号无训练后端。分阶段计时覆盖首批和尾批，完整进程时间仍须后续全量独立测量。

## Task5：完整测试集旧权重回归与完整进程计时

`task-5/` 保存27项标准库测试、实际转换校验、18次完整10000张GPU推理原始记录与独立预测核对。旧权重三种输入模式均9911/10000，与保留参照零差异。unit批量128/1024/4096各五次完整进程中位数1519.771/1536.751/1518.187ms，100ms目标明确未达成；独立profiling的forward+argmax78.942ms不是完整耗时。后续仍须实际默认20epoch训练，再验证其模型，不能用这份旧权重准确率替代。
