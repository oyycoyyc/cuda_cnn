## 已知环境限制

- 远程 Python 3.12 缺少 pyarrow，原始代码的 `make python-tests PYTHON=python3` 因导入错误失败；对应测试已在具有现有依赖的本地主机上通过，不伪称远程通过。
- Windows 原始源码的合规 Bash 脚本含 CRLF，本机首次合规运行另有 GBK 解码错误；Linux 实验副本规范换行后通过。未扩大范围修改本地跨平台测试基础设施。
- Nsight Compute 无性能计数器权限，不能报告实测 GPU 时钟周期；本轮耗时测量不依赖这些计数器。
- 新增快照工具仅支持 Linux/H20；将它纳入 `make all` 的构建意味着本轮不支持 Windows/CUDA 主机上的完整 `all` 构建。本机 Windows 主机测试不受影响，已实际通过。

## 复现当前候选评估

```bash
source /gemini/code/cuda_cnn/scripts/gemini_env.sh
cd /gemini/code/cuda_cnn/runtime-output/evaluate-a-20261027/candidate
env -u CUDA_LENET_PROFILE_EVALUATE /usr/bin/time -f 'wall_seconds=%e' \
  ./build/lenet_cuda evaluate \
  --data /gemini/data-1/test.bin \
  --weights /gemini/code/cuda_cnn/weights/lenet.bin \
  --min-accuracy 0.99 --device 0
```
